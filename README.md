# QJRpkg

A free GitHub repository of QJRpkg package manager.

### Available on:

1. BSD
2. Linux
3. Darwin
4. macOS

### Use:

```
qjrpkg help           - get help
qjrpkg source <repo>  - get package source
qjrpkg install <repo> - install package
qjrpkg remove <name>  - remove package
qjrpkg list           - package list
```
### Example:

```
qjrpkg install https://gitub.com/user/repo.git
qjrpkg source https://gitub.com/user/repo.git
qjrpkg remove repo
```
